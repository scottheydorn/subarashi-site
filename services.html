FAQ

Common questions

Do you work with our existing partner?

Yes. Many engagements run alongside an implementation partner; we focus on DevOps and release engineering so they can focus on functional work.

How do you use AI with our code?

Only as your policies allow. Every proposal names the AI tools involved and how code and data are handled. Local or private-tenant models are an option.

What access do you need?

Read access to your repositories and Azure DevOps or GitHub, plus sandbox environment access for build and deployment work. The schedule starts once access is in place.

Can a package be extended?

Yes, either with a follow-on package or T&M hours.

How many clients do you take on?

A small number at a time, so each engagement gets senior, hands-on attention. If capacity is full, we’ll agree a start date rather than overcommit.
